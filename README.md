# YongBEEP

A minimalist Bluetooth + LAN messenger forked from BeeBEEP 5.9.2-dev
(official SourceForge SVN r1609, GPLv3). Mac ↔ Windows over classic
Bluetooth RFCOMM (text + files ≤5MB), WeChat-style UI.

- `yongbeep/docs/` — design docs (proposal, PRD, TDD, test plan, analysis)
- `yongbeep/poc-bt/` — M1 RFCOMM throughput PoC tester
- Branches: `main` = pristine upstream baseline, `dev` = integration
- Upstream: https://sourceforge.net/p/beebeep/code/HEAD/tree/
