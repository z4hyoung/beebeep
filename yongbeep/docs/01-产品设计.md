## 1. 产品定位

**YongBEEP = 一对邻近但网络不通的电脑之间的私人蓝牙聊天工具。**

一句话：打开就能用——像微信一样聊天、拖个文件就发过去，不需要两台机器在同一个网络，也不需要互联网。

## 2. 目标用户与场景

| 角色 | 描述 | 关键诉求 |
|---|---|---|
| 主用户（Mac） | 技术用户，本项目发起人 | 稳定收发文本/小文件；界面干净现代 |
| 对端用户（Windows） | 同事/家人，可能非技术用户 | 免配置：装上、配对一次、就会用 |

**核心场景**
1. 两机各自连接自己的网络（互不相通），需要互发一段文本/一个 ≤5MB 文件
2. 完全无网络环境（路由器故障/野外），仍可通信
3. 传完即走：不希望为此登录任何账号、不留隐私数据在第三方服务器（蓝牙直连+端到端加密，天然满足）

## 3. 功能规格（MoSCoW）

### 3.1 MUST（第一版必须交付）
| # | 功能 | 细节 |
|---|---|---|
| F1 | 首次启动向导 | 3 步：①设置昵称(默认=系统用户名)+可选头像 → ②蓝牙状态检测（未开则引导去系统设置开启，附图文）→ ③扫描附近 YongBEEP 设备并连接（含系统配对引导：检测到未配对设备时弹分步指引；配对码确认交给系统弹窗） |
| F2 | 会话列表 | 每项：头像/昵称/最后一条消息摘要(单行)/相对时间/未读角标；按最近活跃排序；顶部搜索框（过滤会话） |
| F3 | 单聊文本 | Enter 发送、Shift+Enter 换行；气泡样式（自己右侧强调色+右侧头像，对方左侧+左侧头像，系统/时间戳居中灰字）；发送失败态（红感叹号+点击重发） |
| F4 | 文件发送 ≤5MB | 三种入口：📎按钮选择 / 拖拽进聊天区 / 粘贴剪贴板图片（自动命名 `截图_YYYYMMDD_HHMMSS.png` 发送）；>5MB 拦截并提示；进度条气泡；完成后点击气泡可打开文件/所在目录 |
| F5 | 文件接收 | 默认**自动接收**（微信式，落盘到下载目录），设置可改"每次询问"；接收中进度条气泡；完成时系统通知 |
| F6 | 连接状态指示 | 会话头部显示：🟢蓝牙已连接 / 🟡连接中 / 🔴已断开（点击触发重连）；断线自动重连（指数退避，上限 60s） |
| F7 | 聊天记录 | 本地持久化（复用 BeeBEEP 现有存储）；会话内"清空记录"按钮 |
| F8 | 系统通知 | 新消息（窗口非激活时）、文件接收完成；可整体关闭 |
| F9 | 界面语言 | 跟随系统，支持 简体中文/English |

### 3.2 SHOULD（第一版尽量带）
- 手动暗色模式开关（内置亮/暗两套预设配色，不跟随系统——降低实现风险，跟随系统进 COULD）
- macOS Dock 未读角标 / Windows 任务栏闪烁
- 图片消息在气泡内显示缩略图（点击=打开文件）
- 轻量 emoji 选择面板（系统 emoji 字体渲染，不做表情包管理）

### 3.3 COULD（有余力再做）
- 聊天记录全文搜索
- 蓝牙信号强度指示
- 暗色自动跟随系统
- 多设备（>2 台）同时连接

### 3.4 WON'T（明确不做，砍除清单）
群聊/群管理、语音消息、视频、桌面共享、截图工具、游戏插件、表情包管理与下载、拼写检查、Buzz 震动、蜂巢(Hive)面板、ShareBox 共享箱、用户状态(忙碌/离开等，只保留 在线/离线)、消息撤回、已读回执、公网/互联网通信、>5MB 大文件、断点续传、账号体系。

### 4.3 关键状态枚举
| 对象 | 状态 |
|---|---|
| 会话列表项 | 正常 / 有未读(角标数字) / 传输中(列表项左侧小进度环) |
| 连接 | 🟢已连接 / 🟡连接中(自动重连) / 🔴断开(点按手动重连) |
| 文件气泡 | 发送：传输中(%)→✓已发送 / ✗失败(点击重发)；接收：传输中(%)→✓已接收(点击打开) / ✗失败 |

## 5. 交互流程

1. **首次使用**：向导 3 步 → 系统配对（一次）→ 自动连接 → 直接进主窗口
2. **日常启动**：自动重连上次设备；断开则显示 🔴，后台持续重连
3. **发文本**：输入 → Enter → 气泡即时上屏（乐观 UI）→ 确认后置为已发送；失败→红叹号+点击重发
4. **发文件**：选择/拖拽/粘贴 → ≤5MB 校验 → 进度气泡 → 完成态
5. **收文件**：自动接收落盘 → 进度 → 完成通知+点击打开（设置为"每次询问"时先弹确认）
6. **断线**：自动重连（退避）；期间发送的消息标记"待发送"，重连后自动补发

## 6. 非功能需求

| 项 | 指标 |
|---|---|
| 启动到可交互 | < 2s（M2 硬件实测） |
| 文本端到端 | 正常蓝牙环境下 < 1s |
| 文件吞吐 | ≥100KB/s（M1 PoC 验收底线；低于则按方案降级链重评） |
| 内存占用 | < 200MB |
| 安全 | 全流量端到端加密（复用 BeeBEEP ECDH+AES-256）；本地记录仅本机 |
| 平台 | macOS 13+（arm64 主力）/ Windows 10 1903+ x64 |

## 7. 产品验收标准（G4 用，全部可勾选）

- [ ] 两机断开各自网络（Wi-Fi 关/拔线），仅蓝牙：向导→配对→连接 ≤5 分钟
- [ ] 发送 100 条连续文本无丢失、无乱序
- [ ] 传输 5MB 文件成功且 ≥100KB/s；传输中拔蓝牙→失败态可重发
- [ ] >5MB 文件被拦截并正确提示
- [ ] 断线重连后"待发送"消息自动补发
- [ ] 未读角标/系统通知/Dock 角标（SHOULD 项若实现）行为正确
- [ ] 中文/英文界面切换正确，无硬编码英文残留（新 UI 字符串全部走翻译）
- [ ] 砍除清单（§3.4）中的功能在 UI 上不可见
- [ ] 内存 <200MB，连续运行 8h 无泄漏迹象

## 8. 已拍板的产品默认值（用户可推翻）

| 决策 | 默认 | 理由 |
|---|---|---|
| 文件接收 | 自动接收 | 微信习惯；私密 1:1 场景风险低 |
| 暗色模式 | 手动开关，不跟随系统 | 跟随系统在 Qt5.15/6 Widgets 下实现风险中等，先保交付 |
| 身份体系 | 无账号：昵称+蓝牙地址 | 极简；对端识别靠设备名 |
| 只保留 在线/离线 两种状态 | 是 | 砍掉忙碌/离开等 IM 状态 |
| 消息撤回/已读回执 | 不做 | 不在需求边界内 |
