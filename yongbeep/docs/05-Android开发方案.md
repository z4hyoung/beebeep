## 1. 需求边界（对齐 PRD，裁剪到移动端）

**MUST**：文本聊天、≤5MB 文件收发、蓝牙 RFCOMM 直连、系统配对引导、会话列表+聊天页（微信式）、聊天记录、系统通知、中/英文
**SHOULD**：暗色自动跟随系统（Compose 下近乎免费）、未读角标、图片粘贴发送
**WON'T**：与主程序相同的砍除清单（语音/群/桌面共享/游戏…）+ 移动端新增不做：语音通话、朋友圈式扩展、账号体系

## 2. 架构决策（本方案的核心分叉）

### 决策 A：协议/传输核心怎么来？

| 路线 | 做法 | 优劣 | 推荐 |
|---|---|---|---|
| **B1：复用 C++ 核心（JNI）** | 把 `Protocol + 加密(Rijndael-256/ECDH) + StreamDevice + 文件分块` 编为 Android .so，Qt（Core+Network+Bluetooth）作为库嵌入，Compose UI 经 JNI 桥与之通信 | ✅ 协议零重写、与两端天然互通、加密一致；❌ Qt-as-library 集成摩擦（构建链/事件循环线程化） | ⭐ **推荐** |
| A2：Kotlin 全重写 | 用 Kotlin 重写整个协议栈 | ✅ 纯 Android 技术栈；❌ **Rijndael-256 是非标准算法**（块长 256bit，Android javax.crypto 无此变体，需捆绑 Java 实现并自证与 C++ 版比特级一致）、ECDH 握手时序/帧格式/防重链全部复刻=高风险高工时 | 备选（仅当 B1 集成失败） |

> 类比：Telegram/Signal 的移动端都是"原生 UI + C++ 核心"，这是互通型 IM 的成熟模式。

### 决策 B：蓝牙怎么走？
C++ 核心里 `StreamDeviceBt` 用 QtBluetooth（Android 后端官方支持经典 RFCOMM）——**随 B1 免费获得**，UI 层只做系统配对引导（`BluetoothAdapter` intent）与权限请求（Android 12+ `BLUETOOTH_CONNECT/SCAN` 运行时权限）。

## 3. 技术栈与架构图

```
┌─────────────────────── Android App (Kotlin) ───────────────────────┐
│ UI: Jetpack Compose (Material 3) + Navigation-Compose              │
│     会话列表页 / 聊天页(气泡 LazyColumn) / 扫描配对页 / 设置页          │
│ 状态: ViewModel + StateFlow + Coroutines                            │
├─────────────────────────── JNI 桥 (C++) ───────────────────────────┤
│ CoreBridge.kt ↔ core_jni.cpp：消息收发 Flow、连接状态、文件进度回调     │
├─────────────────────── C++ 核心 (.so, 复用) ─────────────────────────┤
│ Protocol(.h) Rijndael/ECDH  StreamDevice(*/BT)  InlineFileTransfer  │
│ Qt 事件循环跑在独立线程（QCoreApplication 非 GUI 模式）                │
└─────────────────────────────────────────────────────────────────────┘
```

- **蓝牙**：RFCOMM（对端 = Mac/Windows YongBEEP，UUID 与现有一致）
- **LAN**：同样免费复用（与两端在同一局域网时自动互发现）
- 构建：Gradle + CMake/NDK + Qt for Android 的 .so 预编译产物

## 4. UI 规划（微信式，Compose）

```
┌────────────────────┐    ┌────────────────────┐
│ ← 用户名      ●蓝牙 │    │ [会话列表页]         │
│────────────────────│    │ 🔍 搜索             │
│        ┌────────┐  │    │ ┌────────────────┐ │
│        │对方消息  │👤│    │ │◉ Windows-PC ②│ │
│  👤┌───┴───────┘  │    │ │  文件已接收 21:32│ │
│    │ 自己消息(绿) │  │    │ └────────────────┘ │
│    └─────────────┘  │    │ ┌────────────────┐ │
│   [📎 文件卡片 进度] │    │ │◉ MacBook        │ │
│────────────────────│    │ └────────────────┘ │
│ [😀][📎][输入框   ] │    │      [＋ 扫描]      │
│              [发送] │    └────────────────────┘
└────────────────────┘
```
- Material 3 + 微信色板（#07C160/#95EC69/#FA5151，与桌面端 YongTheme 一致）
- 气泡 = Compose `Surface(shape=RoundedCornerShape(8.dp))`——**真圆角零成本**（Compose 不受 Qt 富文本那些限制）
- Markdown：`compose-richtext` 系库或延续 setMarkdown 语义；标记位走同一协议
